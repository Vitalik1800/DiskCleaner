📱 DiskCleaner - Android додаток для безпечного очищення памʼяті

DiskCleaner - офлайн Android-додаток для сканування та безпечного очищення файлової системи з урахуванням обмежень сучасних версій Android (Scoped Storage).
Додаток дозволяє користувачеві вручну обирати директорії, аналізувати вміст та контрольовано видаляти сміттєві файли, мінімізуючи ризик втрати особистих даних.

✨ Функціонал
- 🗂️ Вибір директорій для сканування (включно з SAF)
- 🔍 Рекурсивне сканування файлової системи
- 🧹 Пошук сміттєвих файлів:
  - .tmp, .log, .bak, .cache
  - thumbnails
  - screenshots
- 🔒 Захист користувацьких фото та відео (DCIM/Camera, звичайні зображення)
- 📊 Підрахунок кількості файлів та загального розміру
- ⚠️ Розділення операцій Scan / Clean
- 🧾 Підтвердження видалення через AlertDialog
- 📴 Повна офлайн-працездатність

🧠 Безпека та UX
- Видалення неможливе без попереднього сканування
- Кнопка Clean неактивна до завершення scan
- SAF-доступ лише до директорій, обраних користувачем
- Захищені директорії:
  - DCIM/Camera
  - звичайні фото користувача
- Візуальне розділення безпечних та ризикованих дій

📱 Підтримка Android
- 🤖 Android 7.0 - 9.0
  - Робота з файловою системою через java.io.File
- 🤖 Android 10+ (Scoped Storage)
  - Доступ до файлів через Storage Access Framework
  - DocumentFile API
